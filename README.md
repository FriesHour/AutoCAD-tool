# AutoCAD 自动编号工具

一个简单实用的 AutoCAD AutoLISP 脚本，用于快速创建批量编号文字。

## ✨ 特性

- 🚀 **简单直观** - 点击即可创建编号，无需复杂操作
- 🎨 **自定义格式** - 支持自定义编号前缀（如 XZ-、A-、T- 等）
- 🔢 **灵活起始** - 可从任意数字开始编号
- 🎯 **精确定位** - 在点击位置精确插入编号
- 🖌️ **样式控制** - 可自定义文字颜色、高度和图层
- 📝 **自动递增** - 连续点击自动递增编号

## 📦 安装

1. 下载 `blocknum_auto.lsp` 文件
2. 在 AutoCAD 中输入 `APPLOAD` 命令
3. 选择下载的 `.lsp` 文件加载
4. 开始使用！

## 🚀 使用方法

### 基本使用

1. 输入 `BN` 命令
2. 输入编号前缀（如 `XZ-`，按回车使用默认值）
3. 输入起始编号（如 `1`，按回车使用默认值）
4. 点击要插入编号的位置
5. 继续点击下一个位置，按 ESC 退出

### 命令列表

| 命令 | 功能 |
|------|------|
| `BN` | 主命令：开始创建编号 |
| `BNHEIGHT` | 设置文字高度 |
| `BNCOLOR` | 设置文字颜色 |
| `BNLAYER` | 设置编号图层 |

### 使用示例

```
命令: BN
输入编号前缀 <XZ->: XZ-
输入起始编号 <1>: 5
===================================
编号格式: XZ-1, XZ-2, XZ-3...
起始编号: XZ-5
文字高度: 300
===================================
当前将创建: XZ-5
点击插入编号的位置: [点击位置]
```

## 🛠️ 自定义设置

### 修改默认值

打开 `blocknum_auto.lsp` 文件，修改第 8-13 行的默认值：

```lisp
(if (not *blocknum_layer*) (setq *blocknum_layer* "编号层"))    ; 默认图层
(if (not *blocknum_prefix*) (setq *blocknum_prefix* "XZ-"))      ; 默认前缀
(if (not *blocknum_height*) (setq *blocknum_height* 300))      ; 默认高度
(if (not *blocknum_style*) (setq *blocknum_style* "宋体"))       ; 默认字体
(if (not *blocknum_current*) (setq *blocknum_current* 0))        ; 默认起始号
(if (not *blocknum_color*) (setq *blocknum_color* 1))            ; 默认颜色(红色)
```
