# 更新日志

## [3.0] - 2026-08-07

### 新增
- 🎯 简化操作流程，每次运行时可自定义前缀和起始编号
- 🎨 增强颜色控制功能
- 📝 改进用户界面和提示信息
- 🔧 添加 `BNCOLOR` 和 `BNLAYER` 辅助命令

### 改进
- 移除复杂的自动扫描功能，提高可靠性
- 优化用户体验，操作更直观
- 简化代码结构，提高可维护性

### 修复
- 修复编号中断后重新开始的问题
- 修复字体显示问题

## [2.2] - 2026-08-07

### 改进
- 增强扫描功能，添加详细的调试输出
- 改进错误处理和用户反馈

### 修复
- 优化编号继续功能
- 修复图层创建问题

## [2.1] - 2026-08-07

### 修复
- 移除加粗功能，解决字体显示问题
- 改用单行文字 (TEXT)，提高兼容性

## [2.0] - 2026-08-07

### 新增
- 🎨 添加文字颜色控制
- 🔤 支持自定义字体和高度
- 📋 添加多个辅助命令（BNS, BNR, BNLAYER等）
- 🔄 添加自动扫描现有编号功能

### 改进
- 改用多行文字支持格式化
- 增强错误处理
- 改进用户界面

## [1.0] - 2026-08-07

### 初始版本
- ✨ 基础编号功能

- 🗂️ 独立图层管理
